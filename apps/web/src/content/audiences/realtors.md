## Listings generate comments, not leads

A good listing post gets thirty comments asking for details. Each one is a lead
only if someone answers it, and by the evening most of them have moved on to the
next post in their feed.

## One code per listing

Give each listing a short code in the caption — *DHA6*, *PLOT12* — and set a
keyword automation for each. Commenting the code sends the full details, the
location and the photo link privately, within seconds.

It scales: ten listings is ten automations, and they all run at once.

## Qualify in the same conversation

Use quick-reply chips for budget band and timeline. Two taps and you know whether
this is someone buying this quarter or someone browsing. Then ask for the number —
one tap, normalised, straight into your contacts.

That is the difference between thirty comments and eight calls worth making.

## Be careful with the price

Send the asking price, not a valuation or a negotiation position. Anything about
what an owner would accept, or what a property is really worth, belongs in a
conversation you are actually having.

## Follow up once

Property decisions are slow. One nudge with the details again is worth sending;
after that, the contact record is what matters — when a similar listing comes up,
you already know who asked.
